Say Hi to lI.

A peculiar, esolang where JavaScript source is transformed into a stream made from just two lookalike characters: lowercase l and uppercase I.

What is lI?

lI v0.1 uses canonical Huffman coding to encode source text. The result has a small metadata header, followed by the encoded stream. It’s esolang-inspired in appearance, but the current playground encodes and decodes JavaScript text—it does not interpret lI as a standalone programming language.

Two-symbol stream

Bits are represented using two visually similar characters: l stands for 0 and I stands for 1.

Canonical Huffman

Character frequencies build the Huffman code lengths, then canonical rules assign reproducible bit codes.

Encode & decode

Convert JavaScript source into lI text, decode it back, or run the JavaScript in the local playground.

A tiny peek

The header stores the character count, number of encoded bits, and each character’s Unicode code point and frequency.
